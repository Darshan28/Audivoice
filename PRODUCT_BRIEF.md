# Audivoice — Product Brief

**Tagline:** Give every audience a voice.  
**Site:** [www.audivoice.com](https://www.audivoice.com)

---

## 1. What is Audivoice?

Audivoice is an **interactive feedback and audience engagement** platform. Hosts create a session, share a QR code or short join code, and collect live responses through polls, Q&A-style prompts, quizzes, surveys, and ratings.

Participants can join **without creating an account** when guest access is enabled. Hosts sign in to create and run sessions.

In one sentence: **It’s a simple way to turn a quiet room into an interactive conversation.**

---

## 2. The problem it solves

In reviews, meetings, training, and events, many people stay silent because:

- Speaking up feels awkward or risky
- There’s no easy channel for quick opinions
- Feedback comes too late (or not at all)
- Creating accounts just to answer one poll is a barrier

Audivoice lowers that friction: **share a code → join → respond → see results.**

---

## 5. How it works (4 steps)

1. **Create a session** — Host signs in, names the session, builds slides/activities.
2. **Share access** — Show a QR code or share the short session code.
3. **Collect responses** — Participants join (as guests when enabled) and answer live.
4. **Review feedback** — Host sees live results, then reviews/exports after the session.

Session lifecycle in the product: **Draft → Lobby → Live → (Paused) → Ended**.

---

## 6. What you can run in a session

### Marketing activity framing

Presented to customers as five activity types:

| Activity | Purpose |
|----------|---------|
| **Live polls** | Quick votes and opinions during a session |
| **Q&A** | Collect questions into the conversation |
| **Quizzes** | Check understanding in training/classes |
| **Surveys** | Structured multi-question feedback |
| **Ratings** | Fast scores on concepts or experiences |

### What’s actually in the editor (building blocks)

Sessions are built as a sequence of **interactive slides** and **content slides**:

**Interactive**

- Multiple choice (one or many)
- Yes / No
- Rating (star-style)
- Scale (numeric range with labels)
- Open-ended text
- Word cloud
- Ranking

**Content (presenter slides)**

- Text, Image, Video
- Instructions (how to join/participate)
- Compare (two sides side-by-side)

Those blocks are how hosts compose polls, quizzes, surveys, and the rest.

## 7. Key product capabilities

| Capability | Detail |
|------------|--------|
| Guest join | Participants join with code + optional display name; no host-style account |
| QR / join code | Short join codes (5 characters) for easy sharing |
| Present mode | Lobby + live presenting for the host |
| Live results | Aggregated results update in real time for the host |
| Session settings | e.g. anonymous participation, max participants |
| Results & export | Post-session results view with CSV export |
| Auth for hosts | Google + email magic link (Supabase) |
| Onboarding | Hosts set role, use cases, and typical audience size |
| Capacity target | ~200 concurrent participants per session |

## 11. What makes it different (positioning)

Not “another enterprise webinar suite.” Audivoice is positioned around:

1. **Low friction for participants** — join without an account when guest access is on
2. **Feedback-first** — polls, ratings, surveys, Q&A for decisions and reviews
3. **Situation-flexible** — same tool for design reviews, meetings, training, and events
4. **Simple host workflow** — create → share → present → review

Closest category: **audience engagement / live polling** (Mentimeter-like), with emphasis on **anonymous-friendly feedback** for reviews and meetings.
